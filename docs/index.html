  1. 1

    下载并安装

    打开 DMG，将 Mac Duo 拖入「应用程序」。支持 macOS 14 及以上，通用版本适用于 Apple Silicon 和 Intel。

  2. 2

    允许屏幕录制

    首次使用时，在系统「隐私与安全性」中允许 Mac Duo 截取屏幕，用来呈现过渡画面。

  3. 3

    试播，或轻轻合盖

    点击「全屏试播」体验五秒动效。兼容设备可自动跟随合盖角度；打开屏幕即退出效果。

还想了解

我的 MacBook 支持自动合盖效果吗？+

自动效果需要兼容的铰链角度传感器，目前已在 Mac16,8 / macOS 15.7.9 验证，其他机型的支持情况可能不同。通用安装包支持两种处理器架构，并不代表每款设备都有可用的角度传感器。没有传感器时，仍可使用窗口预览；全屏试播需要正在使用的内置显示屏与录屏权限。

会改变 Mac 的休眠行为吗？+

不会。Mac Duo 遵循系统原有的休眠行为，屏幕关闭后不会继续播放。唤醒后正常显示桌面。屏幕停在半合状态 12 秒未继续移动，也会自动退出效果。

如何立即退出动效？+

打开屏幕，或按 Control + Option + Command + D。设置窗口激活时也可以按 Escape。关闭设置窗口后，App 仍驻留菜单栏；可从菜单栏退出。

可以修改和分享这个项目吗？+

可以。Mac Duo 以 MIT 许可证开源，欢迎查看、修改和分发源码。它是一个独立的视觉实验项目，不隶属于 Apple。前往 GitHub ↗
